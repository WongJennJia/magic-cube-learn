# 魔术方块小达人

给小学生的互动魔术方块教学：从零开始学会还原，再一步步练到 20 秒。

- **9 关课程**：认识方块、转动记号，再到 7 步还原法（小雏菊 → 白十字 → 白色角块 → 第二层 → 黄十字 → 黄色面 → 车灯 → 棱块）。每一关都有 3D 演示、口诀、观察练习和随机练习题。
- **观察训练营**：颜色好朋友、闪眼记忆、找小块、图形侦探、预测高手。
- **跟我还原**：照打乱公式打乱，或输入自己方块的颜色，跟着一步一步还原。
- **计时器**、**20 秒之路**（指法、底十字、F2L 入门、两步顶层 16 个公式）、**口诀卡**。

直接用浏览器打开 `index.html` 就能用，不需要安装。

## 修改

源码在 `src/`：

| 文件 | 内容 |
| --- | --- |
| `engine.js` | 方块模型、转动、新手七步求解器、最少步白十字 |
| `ui.js` | 3D 方块（CSS 3D）、示意图（SVG）、演示播放器 |
| `content.js` | 课程内容、演示案例、观察题 |
| `pages.js` | 各页面、游戏、计时器、路由 |
| `style.css` | 样式（含深色模式） |

改完后运行 `./build.sh` 重新生成 `index.html`。
